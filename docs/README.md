# CliniFlow – hospital campus navigation

Opens in any phone browser. Pick, say or scan where you are and where you want to go. The route is drawn
in 3D across floors, with turn-by-turn directions and a live GPS location dot.

| Page | Building |
|---|---|
| `index.html` | CliniFlow hospital campus: Main & Emergency Block (B–5), OPD Block (G–3), Administrative Block (G–2), plus gate, walkways, parking and ambulance bay. 144 rooms, 76 departments, 5-language voice search |
| `procedures.html` | Mobile-friendly service directory with short requirements and campus locations |
| `college.html` | Optional second demo: SJEC Academic Block III (Ground to 7th floor), same engine |

## Files

| File | What it is |
|---|---|
| `data/hospital.js` | **Campus map**: blocks, floors, rooms, walkways. Generated by `tools/build_hospital_data.py`; includes department names and keywords in 5 languages |
| `data/procedures.js` | **Procedure guide data**: short, reusable visit steps and destination metadata |
| `data/block3.js` | **College map.** Traced from the architect's plans |
| `js/graph.js` | Route finding and turn-by-turn directions |
| `js/app.js` | 3D view, search, floor buttons, GPS location and QR codes. Branding comes from the data file |
| `js/procedures.js` | Service directory, procedure details, and map links |
| `js/voice.js` | Voice search in English, Kannada, Hindi, Malayalam and Tulu |
| `vendor/` | three.js and qrcodejs, bundled so the map works without a CDN |

## Voice search

* **No server needed.** The browser's speech recognition (Chrome, Edge, Android, iPhone Safari) turns speech into text.
  The matcher in `voice.js` then finds the department from words in any of the 5 languages, including code-mixed
  speech ("pharmacy ಎಲ್ಲಿದೆ") and misspellings.
* **Typing works too, in any language,** in the voice box or in "Where to?".
* For facilities on every floor (toilets, lifts, drinking water) it picks the **nearest** one from where you are.
* **Optional SraVaani server** (`../voice-server`): better Indic recognition and Tulu.
  Open `index.html?api=https://your-server` once and the device remembers it.

## Adding another building

Single building: write a data file like `data/block3.js` (rooms as rectangles in metres, doors, corridors, connectors).
Campus: add `blocks` (each with an outline and its floors), per-floor `corridors` with a `zone` (block id or `walkway`),
and `floors` on each lift/staircase, as in `data/hospital.js`. Load it instead of `hospital.js`. Optional keys for branding: `brand`, `types`, `legend`,
`floorNames`, `floorSpoken`, `hints` and `defaults` (see `data/hospital.js`).

## GPS location

Tap the location control to show your position and route from the nearest entrance.
GPS needs HTTPS and location permission. Indoors, choose a start point or scan a door QR code.
When walking on the ground floor, GPS compares successive fixes with the route and reports whether you are following it or should turn around. Indoor accuracy falls back to step and compass tracking.
